# Регионы вузов для отчёта

`institution_regions.json` содержит снимок открытых региональных справочников мониторинга за 2022–2025 годы. Источник: https://monitoring.miccedu.ru/?m=vpo. В JSON сохранены год выпуска мониторинга, исходный ID организации, полное название и регион. Филиалы имеют собственные исходные ID и регион.

Снимок получен 13.11.2026. Всего 4905 записей; одна страница за 2022 год вернула HTTP 500 (URL указан в unavailable_pages). При сверке со входным universities_students_2022_2025.csv все 4684 строки с численностью нашли регион. Это не означает полное покрытие любых других записей БД.

Отчёт не обращается к внешнему сайту. Численность читается из students_amounts, а справочник используется только для определения региона и устранения повторного учёта подтверждённого исходного ID. Неоднозначные или отсутствующие соответствия показываются отдельно. Источник не используется для изменения БД.

Год students_amounts — сохранённый год выпуска мониторинга. Для выбора используется год окончания учебного года, как на дашборде; это соглашение интерфейса, а не утверждение, что фактический период мониторинга совпадает с учебным годом. При добавлении новых лет справочник необходимо обновить.
