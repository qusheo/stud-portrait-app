# Научная деятельность преподавателей

API использует таблицы `elibrary_publications` и `elibrary_teacher_matches` приложения, а не отдельную схему выгрузки. Подготовка таблиц и импорт карточек описаны в `elibrary.md`.

## API

- `GET /portrait/science/statistics/` — общая статистика.
- `GET /portrait/teachers/scientific-activity/?teacher_id=42` — статистика преподавателя.
- Дополнительные параметры: `institution_id`, `year`, `page` (с 1). Размер страницы публикаций — 20.
- Доступ: авторизованные роли admin, centre, institution_admin; остальные получают 401/403.
- Ошибки: 400 — некорректные фильтры, 404 — преподаватель не найден, 503 — таблицы eLIBRARY не установлены.

Ответ `data` содержит `publications_count`, `teachers_count`, `directions_count`, `popular_topics`, `directions`, `by_year`, `coverage`, `publications`, `institutions`, `available_years`, `page`, `page_size`, `match_status`. Доступные годы вычисляются для выбранного преподавателя/вуза независимо от текущего фильтра года.

## Правила подсчёта

Учитываются только связи со статусом confirmed. Совместная работа нескольких преподавателей учитывается один раз в общей статистике. В персональной статистике она включается для каждого связанного преподавателя.
Вуз определяется по текущему справочнику преподавателей. Это не историческая аффилиация на дату выпуска статьи.
Год — год публикации. Неизвестные годы не включаются в конкретный год, но учитываются в общих показателях покрытия.

Популярные темы — ключевые фразы статьи с нормализацией регистра и ё/е, без разрыва словосочетаний. Направления — уникальные исходные рубрики; значения «нет» исключаются. Это разные показатели, без автоматического тематического классификатора.
`direction_groups` содержит отдельные количества и списки рубрик по классификаторам OECD, ГРНТИ и ВАК. Интерфейс показывает количество только выбранного классификатора, не складывая классификации. Поля `directions` и `directions_count` сохраняются для совместимости и отражают совокупность исходных значений.
Русские и латинские ключевые слова выбираются отдельно через `topic_groups`; переводы автоматически не объединяются. Числовые таблицы под диаграммами раскрываются по запросу.
`coverage` отражает наличие ключевых слов, рубрик и неизвестного года. Статистика описывает загруженные и сопоставленные работы, а не всю научную деятельность организации.

## Интерфейс

На странице преподавателей кнопка «Научная деятельность» раскрывает общую панель с выбором вуза и года.
Кнопка перехода в профиль передаёт `teacherId` выбранного преподавателя. В преподавательском профиле доступны личные данные и вкладка научной деятельности. Студенческий профиль не показывает эту вкладку.
Запросы проходят через Api → TeacherService → React Query.

При импорте карточки полное ФИО автора (`full_name`) имеет приоритет перед сокращённым (`name`). Полное несовпавшее ФИО не заменяется совпадением инициалов. Повторный импорт сохраняет ручные решения и отклонённые связи.

## Проверки

Из backend/src: `pytest portrait/endpoints/scienceService/tests`.
Из frontend: `npx vitest run tests/science`, `npm run build`.
SQL-запросы дополнительно проверены на отдельной PostgreSQL-базе: соавторство, исключение кандидатов, фильтры преподавателя/вуза/года и пагинация.
