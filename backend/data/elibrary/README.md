# Данные eLIBRARY

Версионируемый набор публикаций eLIBRARY, связанный с исходным справочником преподавателей ТюмГУ.

`elibrary_sample.dump` — финальный PostgreSQL custom dump (около 52 МБ). Все данные и числовые векторы внутри; дополнительные архивы и распаковка не требуются.

В составе: 1718 преподавателей со всеми 18 исходными полями, 41922 публикации, 23626 кандидатных связей, 2478 подробных карточек и 2286 связей по карточкам. Векторы названий, аннотаций и ключевых слов — отдельные TF-IDF-модели с лемматизацией русского текста, стоп-словами и словосочетаниями.

Из корня репозитория, используя PostgreSQL 18:

```text
createdb studportrait_elibrary_sample
pg_restore --exit-on-error --no-owner --no-acl --dbname=studportrait_elibrary_sample backend/data/elibrary/elibrary_sample.dump
```

Настройки подключения задаются стандартными PGHOST, PGPORT, PGUSER и PGPASSWORD локально. Пароли в Git не сохраняются.
Создавайте отдельную пустую базу; таблицы будут в схеме elibrary_sample. Повторно в заполненную схему дамп не накатывайте.
`backend/create_database.sql` пересоздаёт таблицы приложения и не используется для восстановления набора.

teacher_directory.id — исходный ID преподавателя; teacher_source_rows.payload — все исходные поля.
publications.elibrary_id — ID статьи; teacher_matches — кандидаты из списков; match_evidence — основания совпадения по карточкам.
card_metadata.payload содержит аннотации, ключевые слова, рубрики и даты при наличии.
publication_title_vectors и publication_detail_vectors содержат числовые векторы, соответствующие *_vector_models — словари и параметры.
Примеры запросов: backend/sql/elibrary_example_queries.sql.

Набор неполный: повторяющиеся ответы пагинации не гарантируют полноту каталога. Инициалы не доказывают авторство; полное ФИО и организация — автоматическое основание, не ручная проверка личности.
Проверены SHA-256, SQLite и обратное чтение PostgreSQL custom dump с полным сравнением данных. Восстановление проверено на PostgreSQL 18.7: количества строк, ограничения, представления, размерности и нормализация векторов. Отчёт: postgresql_verification.json.
manifest.json содержит контрольные суммы, export_summary.json — состав таблиц, source_manifest.json — происхождение исходного списка.
Исходный справочник не изменён; посторонние таблицы и аккаунты исходной базы не включены.
